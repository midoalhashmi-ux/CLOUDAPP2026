# تطبيق البث الرياضي — خارطة الطريق والمرجع الشامل

> هذا الملف هو المرجع الرسمي للمشروع. أي نموذج ذكاء اصطناعي يفتح هذا المشروع
> يجب أن يقرأ هذا الملف أولاً قبل أي تعديل، ويحدّثه كلما تغيّر شي أو اكتملت خطوة.

---

## 1. نبذة عن المشروع
تطبيق بث رياضي مبني بـ **Flutter** ومربوط بـ **Firebase**، هدفه الأساسي:
كل شي يتحكم فيه من **لوحة تحكم ويب منفصلة** بدون الحاجة لإصدار تحديث جديد
للتطبيق على المتاجر.

**المستخدم مالك المشروع لا يكتب كود بنفسه** — التطوير بالكامل يتم بمساعدة الذكاء
الاصطناعي، لذلك الوضوح في هذا الملف أهم من أي شي ثاني.

## 2. القرارات المتفق عليها (لا تُغيّر بدون سؤال المستخدم)

| القرار | التفاصيل |
|---|---|
| لوحة التحكم | تطبيق **ويب منفصل تماماً** عن تطبيق الموبايل |
| صلاحيات لوحة التحكم | مستخدم واحد فقط (المالك) — لا حاجة لأدوار متعددة حالياً |
| حماية روابط البث | رابط البث الحقيقي **لا يصل للتطبيق أبداً**. التطبيق يطلب توكن مؤقت من **Cloud Function**، والفنكشن ترجع رابط صالح لمدة قصيرة (5-10 دقائق) مربوط بالجلسة. يتطلب تفعيل **Blaze Plan** في نهاية المشروع فقط |
| الإعلانات (AdMob) | تُفعّل/تُغلق بالكامل من لوحة التحكم في أي وقت |
| الأقسام (Categories) | تُضاف/تُحذف/تُعدّل بالكامل من لوحة التحكم (نص + صورة لكل قسم) |
| الإشعارات | ميزة اختيارية، تُفعّل من لوحة التحكم عند الحاجة |
| وضع الصيانة | زر في لوحة التحكم يقفل التطبيق مؤقتاً برسالة مخصصة |
| الإحصائيات | تتبع بسيط لعدد المشاهدات لكل قناة |
| اللغة | عربي فقط، بدون تعدد لغات |
| محتوى المشتركين المدفوعين | أيقونة **ظاهرة وعادية** باسم "اشتراك" في التطبيق، تطلب كود اشتراك يُتحقق منه عبر Firestore. الأقسام الخاصة مخفية من القائمة الرئيسية ولا تظهر إلا بعد التحقق. **تم تجنب أي إخفاء يهدف لخداع فحص Google Play لأنه مخالفة سياسات وقد يسبب تعليق الحساب بالكامل** |
| التصميم | عصري (Modern UI)، وقابل للتغيير أونلاين بالكامل عبر لوحة التحكم بدون تحديث التطبيق (ألوان، خلفيات، وشكل عام لاحقاً) |

## 3. الحالة الحالية للكود (ما تم إنجازه)
- ✅ هيكل مشروع Flutter نظيف بدون تكرار مسارات
- ✅ نموذجا الأقسام والقنوات (`Category` / `Channel`)
- ✅ خدمة قراءة الأقسام والقنوات من Firestore لحظياً (`content_service.dart`)
- ✅ خدمة روابط البث المؤقتة — هيكل جاهز، **غير مربوطة بعد بـ Cloud Function حماية فعلية**
- ✅ خدمة أعلام الميزات (Feature Flags) لحظية من Firestore
- ✅ ثيم ديناميكي (ألوان + خلفية) يُقرأ من Firestore بدون تحديث تطبيق
- ✅ شاشة رئيسية بتصميم بطاقات عصرية (Grid) تعرض الأقسام بصورها
- ✅ شاشة قنوات القسم (بطاقات تعرض الشعار، الحالة: مباشر/قريباً/انتهى)
- ✅ شاشة المشاهدة (مشغل HLS عبر `video_player` + `chewie`) مع معالجة حالة التحميل والخطأ
- ⚠️ شاشة المشاهدة جاهزة لكن تعتمد على `SecureStreamService` الذي يحتاج تفعيل Cloud Function فعلية (خطوة 2) — حالياً ستظهر رسالة "تعذر جلب رابط البث" وهذا متوقع وطبيعي إلى أن تُفعّل الخطوة القادمة
- ✅ Firebase مربوط فعلياً (مشروع `sports-stream-app-36a7a`) والبناء يعمل على Codemagic

## 4. خارطة الطريق (بالترتيب المقترح للتنفيذ)

1. ~~شاشة قنوات القسم + شاشة المشاهدة~~ ✅ **مكتملة**
2. **حماية روابط البث الفعلية** — Cloud Function + Blaze Plan + توكن مؤقت **(الخطوة القادمة)**
3. **تبويب النتائج المباشرة (Live Score)**
4. **دمج Google AdMob** (بانر + بينية + مكافأة) — قابل للتفعيل/الإغلاق من لوحة التحكم
5. **وضع الصيانة** (Maintenance Mode)
6. **الإحصائيات البسيطة** (عدد المشاهدات لكل قناة)
7. **نظام الاشتراك المدفوع** — أيقونة ظاهرة + كود تحقق + أقسام مخفية
8. **الإشعارات (Push Notifications)** — قابلة للتفعيل من لوحة التحكم
9. **لوحة التحكم الويب الكاملة** — تدير كل ما سبق بدون كتابة كود:
   - إدارة الأقسام والقنوات (نص + صور)
   - تفعيل/إغلاق الإعلانات
   - تفعيل/إغلاق الإشعارات
   - وضع الصيانة
   - إدارة أكواد الاشتراك
   - عرض الإحصائيات

> **ملاحظة:** لوحة التحكم الويب تُبنى تدريجياً مع كل خطوة (كل ميزة تضاف للتطبيق
> تحتاج واجهة تحكم بها بلوحة التحكم)، مو دفعة وحدة في النهاية.

## 5. هيكل بيانات Firestore
```
settings/theme        → { primaryColor, backgroundColor, backgroundImageUrl }
settings/features     → { matchAlerts, liveScoreTab, backgroundAudio, liveChat, adsEnabled, maintenanceMode, maintenanceMessage }
categories/{id}       → { title, order, iconUrl, isPremium }
channels/{id}         → { categoryId, title, subtitle, status, startTime, logoUrl, viewCount }
subscriptions/{code}  → { active, createdAt, expiresAt, unlockedCategoryIds }
```
